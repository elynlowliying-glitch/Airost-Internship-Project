# everyCENT — University Club Budget & Claims Management System

This is the submission of everyCENT, a University Club Budget and Claims Management System project.

# Introduction

everyCENT is an online platform designed to simplify university club financial management. It provides a centralised system for managing activity budgets, reimbursement claims and financial records.

# Main Functions

- User Authentication and Role Management
- Financial Dashboard
- Club Activity and Budget Management
- Reimbursement Claim Submission
- Receipt and Supporting Document Upload
- Claim Approval and Rejection
- Financial Records Management
- CSV Financial Records Export

# Demo

The everyCENT web application is hosted online using Firebase Hosting.

You can access the application through this (https://everycent-404bestiesnotfound.web.app/).

# Frontend & Backend

The root folder contains the source code for the frontend.

- `index.html` — Main application structure and login page.
- `styles.css` — Website styling and responsive layouts.
- `app.js` — Application functionality, authentication, dashboards, claims and financial management.

Firebase is used for backend services:

- Firebase Authentication — Handles user sign-in and authentication.
- Cloud Firestore — Stores user profiles, activities, claims and financial records.
- Firestore Security Rules — Controls access based on user roles.

Google Drive API is integrated to handle receipt and supporting document uploads.
